# 合规与税务指南

> 中国用户境外收入合规处理实用手册
> **免责声明**：本指南仅提供一般性信息，不构成法律或税务建议。具体问题请咨询专业会计师或税务顾问。

## 一、基本概念

### 1.1 你的收入属于什么？

```bash
# 境外收入类型

| 类型 | 示例 | 特点 |
|------|------|------|
| 劳务报酬 | 自由职业、接单 | 按次/按项目 |
| 稿酬收入 | 技术博客、写作 | 有免税额 |
| 特许权使用费 | 销售模板、代码 | 被动性质 |
| 经营所得 | 数字产品销售 | 需要报税 |

# 关键区分：
# - 人在中国境内 = 中国税务居民
# - 收入来源中国境外 = 境外所得
```

### 1.2 需要了解的税率

```bash
# 中国个人所得税（境内居民）

劳务报酬所得：
- 收入<4000：收入-800后计税
- 收入≥4000：收入×80%后计税
- 税率：20%-40%累进

稿酬所得：
- 收入×70%后计税
- 税率：20%

经营所得：
- 税率：5%-35%累进
- 需汇算清缴

# 境外所得抵免
- 已在境外缴税可抵扣
- 需提供完税证明
```

## 二、平台合规配置

### 2.1 账户设置

#### Upwork

```bash
# 1. 注册时
- 使用真实姓名（与身份证一致）
- 正确填写国家：中国
- 银行信息：绑定PayPal或派安盈

# 2. 税务信息
- 在Upwork Tax Information填写
- W-8BEN表格（美国收入预扣用）
- 中国用户通常为0-10%预扣

# 3. 收款建议
- PayPal（美元→人民币）
- 派安盈（推荐，收美元更方便）
- PingPong
```

#### Fiverr

```bash
# 1. 账户设置
- 姓名与证件一致
- 国家选择China
- 收款方式添加PayPal/Payssion

# 2. 税务相关
- Fiverr会自动填写W-8BEN
- 审查收入（美国来源会被预扣）

# 3. 注意事项
- 保留交易记录
- 记录收款时间
```

#### Amazon Associates

```bash
# 1. 申请要求
- 使用真实身份
- 中国地址可申请
- 需验证网站/社媒

# 2. 税务表格
- 填写W-8BEN
- 选择Tax treaty benefits
- 中国与美国有税收协定

# 3. 收款
- 支票/ gift card / 直接存款
- 建议用派安盈收取
```

### 2.2 W-8BEN表格填写指南

```bash
# W-8BEN是预提美国税的豁免表格

填写要点：
1. Part I - 身份信息
   - Name: 你的全名（拼音）
   - Country: China
   - TIN: 中国身份证号（或ITIN申请）

2. Part II - 税收协定
   - 通常不适用（中美无所得税协定）
   - 某些情况下可选Claim a reduced rate

3. Part III - 声明
   - 签名 + 日期

# 注意：
- 表格有效期3年
- 到期前续填
```

## 三、收款与结汇

### 3.1 收款工具对比

| 工具 | 优点 | 缺点 | 适合场景 |
|------|------|------|----------|
| PayPal | 全球通用 | 提现手续费高 | Fiverr/直接客户 |
| 派安盈 | 美元收款方便 | 有年费 | 大额稳定收入 |
| PingPong | 免费开户 | 网点少 | 亚马逊/电商 |
| WorldFirst | 费用低 | 服务一般 | 中小平台 |
| 银行电汇 | 直接 | 手续费高 | 大额偶尔 |

### 3.2 派安盈（Payoneer）注册

```bash
# 注册流程

1. 访问 https://www.payoneer.com
2. 选择"注册账户"
3. 选择"个人"或"企业"
4. 填写信息：
   - 邮箱
   - 手机号（中国）
   - 身份证信息
   - 真实姓名

5. 审核（1-3个工作日）

6. 获取虚拟银行账户
   - 美国银行账户
   - 用于接收美元

7. 提现到国内银行卡
   - 费率约1-2%
```

### 3.3 结汇操作

```bash
# 通过银行结汇流程

1. 收款到PayPal/派安盈
2. 提现到国内银行卡
3. 银行自动结汇

# 额度限制
- 每人每年5万美元便利化额度
- 超过需提供证明材料
- 合理用途说明即可

# 所需材料（超过额度时）
- 合同/Invoice
- 平台收入证明
- 银行流水
```

## 四、税务申报

### 4.1 年度汇算清缴

```bash
# 适用对象
- 中国税务居民
- 综合所得年收入>12万元
- 境外所得>任何金额

# 申报时间
- 每年3月1日 - 6月30日

# 申报方式
- 个人所得税APP
- 税务局网站
- 线下税务局

# 申报步骤
1. 汇总全年收入
2. 计算应纳税额
3. 已在境外缴税可抵扣
4. 多退少补
```

### 4.2 境外所得申报

```bash
# 申报范围
- 在中国境外取得的所得
- 包括：工资、劳务、稿酬、特许权使用费等

# 免税额（2023年标准）
- 境外工资薪金所得：48000元/年
- 境外劳务报酬：800元/次起征点

# 申报表
- 境外所得年度个人所得税申报表（A表）
- 随年度汇算清缴一并申报

# 抵免计算
境外已纳税额 ≤ 抵免限额，可在境内应纳税额中抵免
```

### 4.3 简单计算示例

```bash
# 场景：Fiverr年收入$3000（约¥21000）

计算过程：
1. 换算人民币：约¥21,000
2. 扣除基本减除费用：¥60,000（年度）
3. 扣除后为负，无需缴纳中国个人所得税

# 场景：Fiverr年收入$12000（约¥84000）

计算过程：
1. 换算人民币：¥84,000
2. 减除费用：¥84,000 - ¥60,000 = ¥24,000
3. 适用税率20%：¥24,000 × 20% = ¥4,800
4. 已在Fiverr预扣（如有）可抵扣
```

## 六、常见问题

### 6.1 收入要不要交税？

```bash
Q: 在Fiverr接单赚钱，要不要在中国交税？
A: 需要。中国税务居民有全球纳税义务。

Q: 只有几百美元，也要报税吗？
A: 如果年度总额低于免税额，可能不需实际缴税，但仍建议申报。

Q: 平台已经扣税了，还要在中国交吗？
A: 境外已纳税款可抵扣，具体看抵免计算。
```

### 6.2 收款方式

```bash
Q: 怎么收款最方便？
A: 派安盈 + 国内银行卡是主流方案。

Q: PayPal可以直接用吗？
A: 可以，但提现到银行卡有约$35手续费，建议用派安盈中转。

Q: 可以用家人的账户收款吗？
A: 不建议。资金链路要清晰，避免合规风险。
```

### 6.3 账户安全

```bash
Q: 境外账户会被查吗？
A: 合规使用不会问题。避免大额快进快出。

Q: 需要申报外汇吗？
A: 便利化额度内不需要申报，银行自动处理。
   超过5万美元需提供证明材料。

Q: 如何证明收入合法性？
A: 保存完整的交易记录、合同、交付证明。
```
