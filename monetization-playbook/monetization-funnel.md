## 第一层：流量来源

### 1.1 内容平台布局

#### Medium (英文技术博客)

**配置步骤：**
```bash
1. 注册 Medium Partner Program
   - https://medium.com/partner
   - 需要Stripe账户

2. 申请成为Partner Writer
   - Medium后台 → Settings → Partnership
   - 填写Stripe信息

3. 设置Publication（可选）
   - 创建自己的Publication
   - 统一品牌形象
```

**内容策略：**
```
选题优先级：
1. 高搜索量 + 低竞争 = 立即行动
2. 技能教程类 = 长期SEO
3. 经验分享类 = 建立权威

发布频率：
- 新手：每周1篇
- 进阶：每周2-3篇
- 高手：每天1篇
```

#### Dev.to (开发者社区)

**配置步骤：**
```bash
1. 注册 https://dev.to
2. 完善Profile（英文）
3. 关联GitHub账号
4. 加入相关Tags
```

**最佳实践：**
```
文章结构：
1. Hook（吸引眼球）
2. 正文（实用信息）
3. 代码示例（可复制）
4. 总结+CTA

标签策略：
- 选1个主标签（webdev, python, javascript）
- 选3个相关标签
- 避免过多标签
```

#### 知乎/掘金 (中文流量)

**配置步骤：**
```bash
1. 知乎：
   - 注册账号
   - 完成认证（可选）
   - 关注相关话题

2. 掘金：
   - 注册 https://juejin.cn
   - 开启文章同步
```

### 1.2 社交媒体矩阵

#### Twitter/X

**配置：**
```
Profile优化：
- Banner: 展示专业能力
- Bio: "[职位] | [技能] | [成果]"
- Link: 链接到个人网站/Gumroad

发布节奏：
- 每天3-5条
- 2条技术分享
- 1条个人思考
- 1-2条互动
```

**内容模板：**
```
线程模板：
"我做了[X]，结果[Y]。[N]个关键点："

1️⃣ [第一点]
2️⃣ [第二点]
3️⃣ [第三点]

附代码/截图
```

#### 微信公众号

**配置步骤：**
```bash
1. 注册公众号（个人订阅号即可）
2. 设置自动回复
3. 配置菜单

自动回复设置：
回复"资源"→ 获取免费资料
回复"咨询"→ 引导加微信
```

### 1.3 SEO优化

#### 关键词研究

```bash
工具推荐：
1. Google Keyword Planner（免费）
2. Ubersuggest（免费有限）
3. AnswerThePublic（免费有限）

长尾关键词挖掘：
"[技能] + tutorial"
"[技能] + for beginners"
"[技能] + 案例/effectively/how to"
"[工具] + alternative"
```

#### 技术SEO检查清单

```
□ 标题含关键词（60字符内）
□ Meta描述含关键词（160字符内）
□ H1标签唯一
□ 图片有Alt文本
□ URL含关键词
□ 内链3-5个
□ 外链1-2个权威网站
□ 加载速度<3秒
```

## 第二层：内容策略

### 2.1 内容类型矩阵

```
                    低投入                    高投入
                ┌─────────────┬─────────────┐
           短   │  社交帖子   │   视频教程   │
                │   15分钟   │   2-4小时   │
                ├─────────────┼─────────────┤
            长  │   短文章    │   深度教程   │
                │   45分钟   │   4-8小时   │
                └─────────────┴─────────────┘
                        高转化          低转化
```

### 2.2 爆款内容公式

#### 公式A：教程类
```
标题：我是如何用[技能]做到[结果]的

结构：
1. 背景（1段）
2. 具体步骤（5-8步）
3. 代码/示例
4. 结果展示
5. CTA（引导服务/Gumroad）
```

#### 公式B：资源类
```
标题：最完整的[主题]资源合集

结构：
1. 简介
2. 工具推荐（带链接）
3. 教程推荐（带链接）
4. 模板/代码库（带链接）
5. CTA
```

#### 公式C：经验类
```
标题：[N]个[职业]才知道的[事情/秘密/教训]

结构：
1. 开场故事
2. 逐一展开每个点
3. 每个点附案例
4. 总结+行动建议
```

## 第三层：转化路径

### 3.1 免费工具/资源引流

#### Notion免费模板

**创建流程：**
```
1. 制作Notion模板
   - 客户管理表
   - 项目追踪表
   - 简历生成器
   - 代码片段库

2. 发布为Public
3. 在Gumroad/Ko-fi设置$0

4. 嵌入内容中
   示例："关注公众号，回复'模板'获取"
```

#### GitHub开源项目

```
1. 创建实用工具/库
2. 完善README
3. 发布到GitHub
4. 文章中提及并链接

示例：Web Scraper工具
- README详细
- 包含使用说明
- 链接Fiverr服务
```

### 3.2 CTA设计

#### 各平台CTA位置

```
Medium文章：
- 文首（1句话）
- 文末（推荐阅读+服务卡片）
- 回应评论区问题

Twitter：
- 简介链接
- 线程末尾
- 回复中

GitHub README：
- 简介链接
- Buy Me a Coffee

个人网站：
- 固定悬浮按钮
- 文章底部
- 侧边栏
```

#### CTA文案模板

**软性（适合内容平台）：**
```
"如果你需要帮助，可以在这里联系我"
"如果你觉得有用，可以请我喝咖啡"
"有问题？点击这里预约咨询"
```

**硬性（适合直接转化）：**
```
"需要爬虫服务？点我查看Gig"
"需要定制开发？立即咨询"
"限时优惠：[链接]"
```

```bash
# 1. Profile设置
- 头像：专业照片
- 背景：展示技能
- 语言：English（全球市场）

# 2. Gig图片
- 尺寸：1280x720
- 风格：简洁专业
- 包含关键词

# 3. 价格策略
- Basic: $5-25（新手下单）
- Standard: $50-100（主流定价）
- Premium: $200+（复杂项目）

见 week1-plan.md
```

```bash
# 1. Profile完善度
- 必填：Title, Overview, Skills, Experience
- 选填：Portfolio, Certifications
```

## 漏斗优化指标

### 关键指标追踪

```bash
# 流量层
- 日UV / 月UV
- 粉丝增长率
- 阅读量/曝光量

# 转化层
- 点击率（CTR）
- 注册/关注转化率
- 免费资源下载量

# 收入层
- 订单数
- 客单价
- 转化率
- ROI
```

### 漏斗转化率基准

```
SEO博客 → 邮件订阅：1-3%
邮件订阅 → 购买：5-10%
文章阅读 → Gig点击：0.5-2%
粉丝 → 付费客户：1-5%
```

### A/B测试清单

```
CTA测试：
□ 文案：直接 vs 软性
□ 位置：文首 vs 文末
□ 按钮颜色
□ 按钮文字

内容测试：
□ 标题：数字 vs 问题式
□ 内容长度：短 vs 长
□ 发布时间
□ 配图风格

价格测试：
□ 整数定价（$10）vs 9结尾（$9）
□ 单价 vs 套餐
□ 折扣策略
```
