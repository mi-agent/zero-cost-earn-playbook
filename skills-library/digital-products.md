### 选品黄金公式

```
高需求 + 低竞争 + 你能做好 + 有付费意愿 = 最佳选题
```

```
需求验证工具：
- 微信指数：搜索关键词热度
- 百度指数：搜索趋势
- 5118.com：长尾关键词挖掘
- Google Trends：全球趋势
- 抖音/小红书搜索：看哪类内容点赞高
- 淘宝/闲鱼：看哪类产品销量好

- 闲鱼/淘宝搜索：同类产品数量和销量

- Reddit/Quora：找用户真实痛点
```

### 选题验证三步法

**第一步：竞品调研（1小时）**

```bash
# 在淘宝/闲鱼搜索你的选题关键词
# 记录：
# 1. 搜索结果数量（<100=蓝海，100~500=一般，>500=红海）
# 2. 销量最好的店铺，月销量多少
# 3. 他们的定价是多少
# 4. 用户评价中有什么痛点
```

**第二步：用户访谈（3~5人）**

```
访谈问题模板：
1. "你目前解决这个问题用什么方式？"
2. "现有的解决方案有什么让你不满意的地方？"
3. "如果有一个产品能解决XX问题，你愿意付多少钱？"
4. "你见过的最好产品是什么样的？"

判断标准：
- 3人以上表示愿意付费 > 产品可行
- 普遍痛点 > 你的产品方向
```

**第三步：最小可行性测试（1周）**

```
冷启动测试策略：
1. 在小红书/抖音发布相关内容（选题相关内容）
2. 观察：
   - 点赞/收藏比例（收藏>点赞=需求强）
   - 评论中的问题（高频问题=痛点）
   - 私信/评论问"有没有卖"
3. 如果有3~5人主动问购买方式 > 可行

提前测试定价：
- "如果出这个教程，你们觉得值多少钱？"（评论区调研）
```

## 五、定价与销售心理学

### 定价策略

**锚定定价法**
```
错误：直接卖¥99
正确：
- 先展示"价值¥500的完整版"
- 再展示"特价¥99"
- 制造价值对比，让¥99显得便宜
```

**套餐定价法**
```
基础版：¥29（3套模板）
标准版：¥59（10套模板）← 主推
高级版：¥99（20套+教程+咨询）

心理学：大部分人选择中间档（¥59）
```

**早鸟定价法**
```
新品上线前：
- 预告：即将推出原价¥199课程
- 早鸟价：¥99（限量100名）
- 效果：刺激立即购买
```

### 提升转化率技巧

| 技巧 | 说明 | 效果提升 |
|-----|------|---------|
| 限时优惠 | 设置倒计时 | 30%~50% |
| 限量名额 | "仅剩23个" | 20%~30% |
| 好评截图 | 展示真实反馈 | 15%~25% |
| 退款保证 | "不满意全额退款" | 20%~40% |
| 赠品策略 | 主产品+小赠品 | 15%~20% |
| 分期付款 | 花呗/信用卡分期 | 10%~20% |

## 六、避坑指南

### 🚫 产品制作雷区

| 错误 | 后果 | 正确做法 |
|-----|------|---------|
| 闭门造车 | 没人买 | 先验证需求再制作 |
| 价格太低 | 累死还赚不到钱 | 参考竞品，定价适中 |
| 质量太差 | 差评多，退款高 | 做自己能做到的最好质量 |
| 内容不全 | 用户投诉 | 列出承诺的每一项内容 |
| 没有使用说明 | 不会用=差评 | 必须提供使用教程 |

### 🚫 销售雷区

| 错误 | 后果 | 正确做法 |
|-----|------|---------|
| 夸大宣传 | 退款+投诉 | 真实描述产品内容 |
| 不给退款 | 差评+封店 | 设置合理退款政策 |
| 盗用素材 | 法律风险 | 使用原创或正版授权 |
| 刷单 | 封店 | 真实销售，慢慢积累 |
| 虚假发货 | 违规 | 自动发货系统设置正确 |

### ⚠️ 版权与合规

```
必须避免：
- 直接复制别人的模板/内容
- 使用未授权的字体（思源黑体免费，商用注意）
- 使用未授权的图片（Unsplash/Pexels免费）
- 剽窃他人课程内容
- 虚假宣传"官方授权"等

建议：
- 所有素材使用正版/原创
- 保留创作证据（源文件）
- 注册版权（可选，¥1,000左右）
- 产品描述明确授权范围（个人/商用）
```
